# קליטת פניות אוטומטית

הטופס באתר לא שומר פניות לבד. כדי שכל פנייה תגיע ליועץ, מחברים אותו ל-Google Apps Script שרושם אותה ב-Google Sheets ושולח מייל. זה חינמי, ולא דורש שרת.

## מה מקבלים

- **גיליון "פניות"** עם שורה לכל פנייה: נושא, שם, טלפון, זמן נוח, היקף, מה הגולש בדק באתר (מחשבון, מבחן לחץ, מחשבון רכישה), מקור ההגעה (utm, גוגל, הפניה) וסיכום מוכן לשיחת ההיכרות.
- **עמודת סטטוס** עם רשימה נפתחת (חדש, חזרתי, נקבעה פגישה, בטיפול, נסגר, לא רלוונטי), כמו CRM קטן. אפשר לסנן לפי נושא ולפי סטטוס.
- **מייל ליועץ** על כל פנייה חדשה, עם הסיכום.
- **הגנות:** בדיקת נתונים בצד השרת, מלכודת לבוטים, הגבלת קצב לפי טלפון, וחסימת נוסחאות בגיליון.

## התקנה (כ-10 דקות)

1. יוצרים Google Sheet חדש בחשבון של העסק.
2. בתפריט: **הרחבות ← Apps Script**. מוחקים את מה שיש ומדביקים את התוכן של `lead-webhook.gs`.
3. ממלאים את `ADVISOR_EMAIL` (לאן לשלוח התראות) ושומרים.
4. **פריסה ← פריסה חדשה ← סוג: אפליקציית אינטרנט.** מריצים בתור: אני. מי יכול לגשת: כל אחד. מאשרים את ההרשאות.
5. מעתיקים את כתובת ה-Web App ומדביקים אותה ב-`index.html`, בשורה `const LEAD_ENDPOINT = '';`.
6. שולחים פנייה לבדיקה מהאתר, ובודקים שהשורה נוספה לגיליון ושהמייל הגיע.

מהרגע הזה, האתר מציג "הפרטים התקבלו" רק אחרי שהסקריפט אישר שהשורה נשמרה. אם השליחה נכשלת, הגולש רואה הודעה על כך, עם אפשרות לנסות שוב או לשלוח בוואטסאפ.

## עוד חיבורים אפשריים

- **קביעת פגישות:** קישור ל-Google Calendar (דפי הזמנת פגישות) או ל-Calendly, בשורה `const BOOKING_URL = '';`. הכפתור "קביעת שיחה ביומן" יופיע ליד פרטי הקשר ובמסך התודה.
- **מדידה:** האתר שולח ל-`window.dataLayer` אירועים בלי פרטים אישיים: שימוש בכלים, שלבי הטופס, שליחה מוצלחת או כושלת, לחיצות וואטסאפ. כדי לראות אותם צריך להתקין Google Tag Manager עם חשבון של העסק, ולהוסיף באנר הסכמה לעוגיות לפני שמפעילים כלי מדידה.
- **CRM:** אם העסק עובד עם CRM (Monday, HubSpot, Pipedrive), אפשר להחליף את רישום השורה בסקריפט בקריאה ל-API שלו. זה דורש מפתח API של העסק.
- **הודעת אישור ללקוח** בוואטסאפ או ב-SMS דורשת חשבון WhatsApp Business API או ספק SMS.

## מה לא נבדק

הסקריפט לא הורץ בפועל בסביבת Google, כי זה דורש חשבון של העסק. הלוגיקה של האתר (שליחה, הצלחה, כישלון, ניסיון חוזר) נבדקה מול שרת דמה מקומי שמחזיר את אותן תשובות.

## פרטיות

אחרי החיבור, הפניות נשמרות בגיליון של העסק ב-Google. צריך לעדכן את מדיניות הפרטיות (`privacy.html`) בהתאם, ולהגביל את הגישה לגיליון לאנשים שצריכים אותה. הכנסה חודשית שמוזנת במחשבון הרכישה לא נשלחת לשום מקום.
