# ספר קונספטים למותג: חממות והצללה

ארבעה כיווני מותג לחברה שבונה חממות חקלאיות ומערכות הצללה לבתי ספר: חדשנות ירוקה, טבעי וידידותי, ילדים וחינוך, תעשייתי ומקצועי.
לכל קונספט יש פלטה, טבלת ניגודיות מחושבת, גופנים עם תמיכה בעברית, סקיצת לוגו, רכיבי ממשק בכל המצבים, אייקונים, כיוון צילום, טון ומיקרוקופי,
דף תקציר לעיצוב ולפסיכולוגיה עם השערות לבדיקה, וקובץ טוקנים. בסוף העמוד: טבלת השוואה, צעדים הבאים והערכת שעות.

פותחים את `index.html` בדפדפן. העמוד מסומן noindex, כך שלא יופיע במנועי חיפוש.

## מבנה

```
index.html          ספר המותג (נוצר אוטומטית, לא לערוך ביד)
components.css      כפתורים, שדות, כרטיס ופס התקדמות. משותף לכל הקונספטים
tokens/*.css        משתני CSS לכל קונספט (נוצרים אוטומטית)
tools/build.py      כל הנתונים: צבעים, טקסטים, השערות. מחשב ניגודיות ובונה את הקבצים
tools/shell.html    המעטפת והעיצוב של העמוד
```

## שינוי צבע או טקסט

עורכים את `tools/build.py` (או את `tools/shell.html` למעטפת) ומריצים:

```
python3 greenhouse-brand/tools/build.py
```

הסקריפט מחשב את כל יחסי הניגודיות לפי WCAG 2.1, ונעצר עם שגיאה אם צירוף שבשימוש לא עומד ב-AA.

## שימוש בטוקנים בפרויקט אחר

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Hebrew:wght@400;600;700&family=Noto+Sans+Hebrew:wght@400..700&display=swap">
<link rel="stylesheet" href="tokens/eco-tech.css">
<link rel="stylesheet" href="components.css">

<body data-concept="eco-tech">
  <button class="gh-btn gh-btn--primary">תיאום סיור בחממה</button>
</body>
```

כתובת הגופנים של כל קונספט כתובה בראש קובץ הטוקנים שלו.

## מה תוקן מהטיוטה המקורית

- **ניגודיות:** טקסט לבן על `#4CAF50` נותן 2.78:1 ולא 4.9:1. גם מצבי מעבר עכבר בהירים, גבולות שדה `#CCCCCC`, טקסט לבן על צהוב וטורקיז, וכתום כצבע קישור נכשלים. הצירופים מהטיוטה מוצגים בכל קונספט, תחת "צירופים מהטיוטה שלא עומדים בתקן".
- **גופנים:** ל-Inter, IBM Plex Sans, PT Serif, Fredoka One, Roboto Condensed, IBM Plex Mono, Noto Sans, Verdana ו-Helvetica אין עברית. כל קונספט קיבל זוג שתומך בעברית.
- **מיקרוקופי:** כפתורים בשם הפעולה, פנייה ברבים, והסרה של ניסוחים לא ברורים ("לא לדלג על הכניסה") ושל הבדיחה בקונספט התעשייתי.
- **השערות:** לכל השערה נוספו שיטת בדיקה ומדד.
- **הערכת שעות:** נוספו המשימות שהטיוטה הזכירה ולא העריכה (סדנה, בדיקות משתמשים, אבטיפוס, לוגו סופי), מסומנות כהערכה שלנו.

## מה עוד חסר

- **שם המותג:** "שם המותג" הוא מקום שמור. הסימנים הם סקיצות כיוון ולא לוגו סופי.
- **צילומים:** המסגרות הן מקום שמור. כל מסגרת מתארת את הצילום הדרוש.
- **דירוג ההשוואה** לקוח כמו שהוא מהטיוטה, וכדאי לאמת אותו בסדנת בעלי העניין.
