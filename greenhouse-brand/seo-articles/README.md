# מרכז הידע של מיפתח: 5 מאמרי SEO

| מאמר | קובץ | מילת מפתח ראשית |
|---|---|---|
| בית רשת חקלאי (מאמר עמוד) | site/beit-reshet.html | בית רשת |
| בית רשת לבננות | site/beit-reshet-bananot.html | בית רשת לבננות |
| רשת נגד ברד למטעים | site/reshet-neged-barad.html | רשת נגד ברד |
| בית רשת לאבוקדו | site/beit-reshet-avocado.html | בית רשת לאבוקדו |
| השקעה בחקלאות בחו״ל בשיטת Turnkey | site/chava-haklait-turnkey.html | השקעה בחקלאות בחו"ל |

- `site/index.html`: עמוד מרכז הידע. `site/pack.html`: חבילת הפצה (טבלת SEO, פוסטים לפייסבוק, אינסטגרם ולינקדאין, צ׳קליסט השקה).
- בכל מאמר: נתונים מובנים (BlogPosting, Organization, BreadcrumbList, FAQPage), canonical, Open Graph, תוכן עניינים, מקורות ממוספרים.
- תמונות שמסומנות "הדמיה" נוצרו ב-AI (Higgsfield) להמחשה. "ארכיון מיפתח" = צילומים מתיקיית החברה.
- `research/`: בריף, אסטרטגיית SEO, חבילת נתונים עם מקורות, אסטרטגיית שיווק והמרה, ערכת SEO טכנית.
- בנייה מחדש: `cd tools && python3 build.py && python3 pack.py` (המאמרים ב-`tools/articles/aN.py`; הפלט נכתב ל-`tools/site/`).
