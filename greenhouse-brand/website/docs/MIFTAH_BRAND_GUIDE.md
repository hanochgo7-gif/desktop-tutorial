# ספר המותג של מיפתח פרויקטים

מיפתח פרויקטים - חקלאות שיש לה בית

## מי אנחנו

אנחנו מתכננים, מייצרים ומקימים פרויקטים חקלאיים בישראל ובעולם כולו, מאז 2003. מיפתח היא חברה משפחתית מכפר מסריק, בניהול הבעלים, מרב איל הספל ויפתח הספל.

## ההבטחה שלנו

כתובת אחת, החל מהתכנון ועד ההקמה, בישראל ובעולם כולו.

## חמשת עמודי המותג

1. **תכנון לשטח.** ממפים את הקרקע, צורכי הגידול והמגדל, הניקוז, הגישה וכיווני הרוח, ואז מתכננים את המבנה ואת כתב הכמויות.
2. **מפעל שלנו.** עיבוד וייצור החומרים ובקרת איכות לפני היציאה לשטח.
3. **הקמה ומסירה.** הצוותים שלנו בעלי הכשרה לעבודה בגובה, ומוסרים ללקוח מבנה גמור.
4. **בישראל ובעולם.** מיליוני מ״ר של פרויקטים חקלאיים ופתרונות הצללה: פורטוגל, ספרד, מקסיקו, הודו, הונדורס, גאורגיה, בלארוס ואפריקה.
5. **מילה זו מילה.** חברה משפחתית; עובדים מול הבעלים.

## מה אנחנו בונים

- בתי רשת לגידולים חקלאיים
- פתרונות הצללה לאזורי תפעול
- שוברי רוח
- הדליה ותמיכה
- חוות עד מפתח בחו״ל, יחד עם שותפים
