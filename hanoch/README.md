# חנוך גוטובסקי – אתר אישי ופורטפוליו

אתר סטטי בעברית (RTL), בלי שלב בנייה. הקונספט: "האתר שבונה את עצמו מול העיניים".

## מה יש בו
- **פתיח:** קווי שרטוט נמתחים והשם מוקלד (בביקור חוזר באותה לשונית הפתיח מקוצר).
- **פתיחה – במה תלת־ממדית (`js/stage.js`, Three.js 0.169):** האות ח מזכוכית אמיתית (שבירה, פיזור צבעים, קשתיות) שבנויה מקווי המתאר של Frank Ruhl Libre, והשם מאחוריה נשבר דרכה. סביבה מסתובבים שישה חפצים, אחד לכל לקוח: אקדח תדלוק, כפפת אגרוף, שקית חטיפים, בקבוקון סרום מזכוכית ורודה, פיתה פלאפל ו-π. מעבר על חפץ מאט את המסלול ומציג את שם הלקוח; לחיצה פותחת את סיפור הפרויקט. בגלילה האות מתפרקת לקווי שרטוט, ובמצב רנטגן החפצים הופכים לרשת כחולה.
  - החפצים נוצרו ב-Higgsfield: תמונה (GPT Image 2.5) ← מודל תלת־ממדי (Meshy 7, איכות מרבית, חומרי PBR), ודוחסו ב-gltf-transform (meshopt + WebP) מ-52MB ל-2.8MB. גם תמונת הסטודיו להשתקפויות (`3d/studio.jpg`) נוצרה שם.
  - איכות מסתגלת: אם המכשיר איטי הרזולוציה יורדת. בלי WebGL 2 או ב"הפחתת תנועה" הבמה לא נטענת, והפתיחה חוזרת לחלקיקים או לטקסט.
- **החפץ בתוך כל פרויקט (`js/gallery.js`):** כל שורת פרויקט וכל סיפור פרויקט מציגים את החפץ של הלקוח בתלת־ממד; גוררים כדי לסובב, והוא ממשיך להסתובב באינרציה. קנבס אחד קבוע מצייר את כל המשבצות (הקשר WebGL יחיד, כל מודל נטען פעם אחת).
- **חלקיקים:** `js/particles.js` (בלי ספריות). בקטע "קשר" הם מתאספים ל"בואו נבנה."; אם הבמה לא נטענה, הם גם יוצרים את השם בפתיחה.
- **צלילים:** כפתור "קול" למעלה (כבוי כברירת מחדל). צלצול זכוכית לכל חפץ, משב בפתיחת פרויקט ורעש רקע נמוך – הכול מסונתז בדפדפן.
- **מניפסט:** המילים מתמלאות לפי הגלילה.
- **עבודות:** שישה פרויקטים כ"מסכים חיים": במעבר עכבר העמוד נגלל בתוך הדפדפן. לחיצה פותחת את סיפור הפרויקט מתוך המסך עצמו.
- **לפני / אחרי:** אלנביס הישן מול החדש עם קצה נוזלי, ומספרים שמתכווצים.
- **תהליך:** כרטיס דוגמה שעובר שרטוט ← שלד ← חומר ← תנועה לפי הגלילה.
- **מצב רנטגן:** כפתור למעלה או מקש X. עדשה שמראה את השלד, רשת 12 עמודות, ותווית עם התגית, המידות והגופן של כל אלמנט.

בהעדפת "הפחתת תנועה", או אם GSAP לא נטען, הכול מוצג מיד וסטטי.

## קבצים
| קובץ | מה יש בו |
|---|---|
| `index.html` | המבנה והתוכן |
| `css/hanoch.css` | העיצוב |
| `js/hanoch.js` | ההתנהגות, ונתוני סיפורי הפרויקטים (`DATA`) |
| `js/particles.js` | מנוע החלקיקים |
| `js/stage.js` | הבמה התלת־ממדית |
| `js/gallery.js` | החפץ התלת־ממדי בכל פרויקט |
| `3d/` | ששת החפצים (GLB) ותמונת הסטודיו |
| `work/` | צילומי האתרים (מסך מלא, עמוד ארוך, טלפון) ופריימים של AMS |

## להשלים לפני עלייה לאוויר
- **פרטי קשר:** הקישורים לוואטסאפ ולמייל ב-`index.html` הם זמניים (מסומנים `data-todo`).
- **קישורים חיים:** כשהאתרים יעלו לכתובות הסופיות אפשר להוסיף כפתור "לאתר" בסיפור כל פרויקט.
- **הצהרת נגישות:** כמו בשאר האתרים.

## הרצה מקומית
```
cd hanoch && python3 -m http.server 8080
```
