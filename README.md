# אתר ש. גוטובסקי

אתר סטטי בעברית (RTL) לחברת ש. גוטובסקי: הקמה ושיפוץ תחנות דלק, תחנות גז, צנרת דלק, עבודות עפר ומערכות דלק לדאטה סנטר.

## כיוון עיצובי

עיצוב "קינטי-תאגידי" בהשראת אתרי קבוצות בנייה גדולות: טיפוגרפיה ענקית וכבדה (Heebo 900), שחור ונייר חם, הדגשה בכחול הלוגו,
תמונות במסך מלא ואנימציות גלילה (GSAP + ScrollTrigger מ-cdnjs): מסך טעינה, כותרות שעולות מילה-מילה, פרלקסה, טקסט שמתמלא בגלילה,
רשימת תחומים עם תמונה שעוקבת אחרי העכבר, פרויקטים בגלילה אופקית מוצמדת, מונים, קו תהליך, כפתורים מגנטיים וסמן מותאם.
ללא GSAP, בהעדפת "הפחתת תנועה" של מערכת ההפעלה, או כשמפעילים "עצירת אנימציות" בתפריט הנגישות – הכול מוצג מיד ובלי תנועה.

## מבנה הקבצים

```
index.html                 עמוד ראשי (כל הקטעים)
accessibility.html         הצהרת נגישות
privacy.html               מדיניות פרטיות
articles/                  שלושה מאמרי SEO
css/styles.css             עיצוב
js/main.js                 תפריט נייד, גלריה, טופס
js/a11y.js                 תפריט נגישות
images/                    תמונות ולוגו
sitemap.xml, robots.txt    קבצי SEO
```

## הרצה מקומית

פותחים את `index.html` בדפדפן, או מריצים שרת פשוט:

```
python3 -m http.server 8080
```

ונכנסים ל-http://localhost:8080

## העלאה לאוויר

האתר לא דורש שרת או בנייה. אפשר להעלות את כל הקבצים לכל אחסון סטטי:

- **GitHub Pages:** בהגדרות הריפו, Pages, לבחור את הענף הראשי ותיקיית השורש.
- **Netlify / Vercel / Cloudflare Pages:** לגרור את התיקייה או לחבר את הריפו.
- **אחסון רגיל:** להעלות את הקבצים ב-FTP לתיקיית השורש.

## נגישות וחוק

האתר בנוי לפי ת"י 5568 (WCAG 2.0 AA) כנדרש בתקנות שוויון זכויות לאנשים עם מוגבלות: ניווט מקלדת, קישור דילוג לתוכן,
מבנה סמנטי, טקסט חלופי לתמונות, ניגודיות תקינה, כיבוד "הפחתת תנועה", תפריט נגישות מובנה (`js/a11y.js`) והצהרת נגישות.
הטופס כולל הודעת פרטיות לפי סעיף 11 לחוק הגנת הפרטיות, ויש עמוד מדיניות פרטיות.
מומלץ להריץ בדיקה עם כלי כמו axe או WAVE לאחר השלמת התוכן, ולעדכן את הצהרת הנגישות בהתאם.
