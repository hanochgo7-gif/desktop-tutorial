# אתר ש. גוטובסקי

אתר סטטי בעברית (RTL) לחברת ש. גוטובסקי: הקמה ושיפוץ תחנות דלק, תחנות גז, צנרת דלק, עבודות עפר ומערכות דלק לדאטה סנטר.

## מבנה הקבצים

```
index.html                 עמוד ראשי (כל הקטעים)
articles/                  שלושה מאמרי SEO
css/styles.css             עיצוב
js/main.js                 תפריט נייד, גלריה, טופס
images/                    תמונות ולוגו
sitemap.xml, robots.txt    קבצי SEO
```

## הרצה מקומית

פותחים את `index.html` בדפדפן, או מריצים שרת פשוט:

```
python3 -m http.server 8080
```

ונכנסים ל-http://localhost:8080

## העלאה לאוויר

האתר לא דורש שרת או בנייה. אפשר להעלות את כל הקבצים לכל אחסון סטטי:

- **GitHub Pages:** בהגדרות הריפו, Pages, לבחור את הענף הראשי ותיקיית השורש.
- **Netlify / Vercel / Cloudflare Pages:** לגרור את התיקייה או לחבר את הריפו.
- **אחסון רגיל:** להעלות את הקבצים ב-FTP לתיקיית השורש.
