2. **לבדוק אם השינוי מוכר.** אם חנוך או העמותה שינו פרטים בכוונה, לעדכן את רשימת המאושרים ב-`.github/scripts/sayeret_nahal_integrity.py` ולסגור את ההתראה.
3. **אם השינוי לא מוכר:**
   - **לנעול את החשבון:**
     - להחליף את סיסמת הגיטהאב.
     - בהגדרות האבטחה: Sessions → לנתק את כל השאר.
     - Personal access tokens → למחוק את כל מה שלא מוכר.
     - Applications → לבטל אפליקציות לא מוכרות.
     - SSH keys → למחוק מפתחות לא מוכרים.
   - **להוריד את הדף:** במאגר, למחוק את `sayeret-nahal/index.html` או להחזיר גרסה טובה (ראו "שחזור"). עדיף דף ריק מדף עם חשבון בנק של תוקף.
   - **לעדכן את העמותה (חזקי, 050-734-7952):** לפרסם בערוצי העמותה שלא להעביר כסף לפי הדף עד הודעה חדשה, ולוודא פרטי בנק רק בטלפון.
4. **אם כבר הועבר כסף לחשבון זר:** להתקשר מיד לבנק (לאומי), למשטרה (100) ולמערך הסייבר הלאומי (119), ולהגיש תלונה. זמן התגובה קריטי להקפאת כספים.

## שחזור (Disaster Recovery)

- **מקור האמת:** הענף `claude/task-d-pdf`, תיקייה `landing/`. משם בונים עם `python3 build.py`, ומעתיקים את `index.html` ואת `assets/` אל `sayeret-nahal/` בענף `main`.
- **חזרה לגרסה טובה:** `git log -- sayeret-nahal/index.html` ואחר כך `git revert <commit>`, או `git checkout <commit-טוב> -- sayeret-nahal/` ו-push.
- **אם הדף עצמו לא זמין** (GitHub Pages נפל): לפרסם ב-WhatsApp את הקישור הישיר לקמפיין ב-Jgive.
- **גיבוי:** המאגר עצמו הוא הגיבוי (כל ההיסטוריה ב-git). מומלץ גם עותק מקומי: `git clone` פעם בחודש, לדיסק נפרד.
- **יעד זמן:** להוריד דף שנפגע תוך שעה מההתראה, ולהחזיר גרסה טובה תוך 4 שעות.
