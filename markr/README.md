# מרקר (Markr)

עותק של "מרקר – המחברת שמסמנת לך מה חשוב" (by Omer Ezri), לעבודה על עיצוב וחוויית משתמש.

- `index.html` – כל האפליקציה בקובץ אחד (HTML + CSS + JS).
- גרסה חיה עם כל היכולות (שמירה בחשבון, AI, העלאת קבצים): https://claude.ai/artifact/YDh9LaKWKN3erUvL8ZR4jH
- הרצה מקומית: `python3 -m http.server 8080` ואז http://localhost:8080/markr/ .
  מחוץ ל-Claude אין AI וסנכרון; הכול נשמר ב-localStorage של הדפדפן.

## שינויים

- **סבב UX 1:** כפתורי הקיצור במסך הבית ממלאים את כל הרוחב; כרטיסי הכלים בעמוד הקורס נמתחים לרוחב מלא;
  שורת הכפתורים בחלונות (הגדרות, היכרות) נשארת דבוקה לתחתית, כך ש"סגירה" תמיד זמין.
