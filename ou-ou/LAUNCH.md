# או או — מה עובד עכשיו ומה חסר להשקה

אתר סטטי (HTML/CSS/JS ללא בנייה). פותחים את `index.html` בדפדפן. כל ההגדרות העסקיות ב-`js/config.js`.

## עובד עכשיו
- [x] דף בית מלא: גיבור, למה זה עובד, איך משחקים (זוג / קבוצה, מהחוקים האמיתיים), "שלפו קלף", למי מתאים, הסיפור, מה בקופסה, לעסקים, שאלות, CTA.
- [x] "שלפו קלף" אינטראקטיבי עם 5 הקלפים שכבר פורסמו בפלייר + שיתוף לחבר שינחש.
- [x] סל קניות (נשמר בדפדפן), כמות, צ'קאאוט: פרטים, בחירת משלוח, מתנה למקבל עם ברכה, אישור תקנון.
- [x] **ההזמנה נשלחת לרויטל בוואטסאפ** כהודעה מסודרת. רויטל מאשרת, גובה (ביט/אשראי) ומפיקה קבלה במורנינג.
- [x] טופס לעסקים / סדנאות → וואטסאפ. כפתור וואטסאפ צף.
- [x] טיוטות: תקנון (כולל ביטול עסקה לפי החוק), פרטיות, הצהרת נגישות.
- [x] RTL, מובייל, מקלדת, `prefers-reduced-motion`, Schema של Product, נבדק ב-1366px וב-390px ללא שגיאות קונסול.

## לא הומצא — ולכן לא מופיע
ביקורות/המלצות, צילומי "לקוחות", סרטון, זמני משלוח, מחירי משלוח, מספר רמות העומק, משך משחק בדקות. כל אחד מהם נכנס כשיש חומר אמיתי.

## חסר להשקה (לפי סדר)
1. **אישורים מרויטל:** מספר הוואטסאפ, השם המלא + מס' עוסק (לתקנון), אילו קלפים נוספים מותר לחשוף ב"שלפו קלף", מספר רמות העומק.
2. **דומיין** + העלאה (GitHub Pages / Netlify / Vercel).
3. **סליקה:** לפתוח חשבון (Grow / PayPlus / מורנינג) ולשים קישור תשלום ב-`paymentUrl`. עד אז — וואטסאפ.
4. **משלוחים:** הצעות מחיר (קרגו / HFD / דואר ישראל) → מחירים ב-`shipping` + זמני אספקה בתקנון ובשאלות.
5. **צילום:** קופסה, קלפים, משחק אמיתי (באישור המשתתפים), תמונה של רויטל → גלריה + "אודות".
6. **סרטון "איך משחקים"** (60 שניות).
7. **המלצות אמיתיות** → סקשן הוכחה חברתית.
8. **משפטי:** עו"ד עובר על תקנון ופרטיות; להסיר את סימון "טיוטה".
9. **מדידה:** Google Analytics + פיקסל מטא/טיקטוק + באנר הסכמה (ולעדכן מדיניות פרטיות).
10. **סימן מסחר** "או או" — בדיקה ברשות הפטנטים.
11. תמונת שיתוף (og:image) מצילום אמיתי.
