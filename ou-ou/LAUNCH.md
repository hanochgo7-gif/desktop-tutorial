# או או — מה עובד עכשיו ומה חסר להשקה

אתר סטטי (HTML/CSS/JS ללא בנייה). פותחים את `index.html` בדפדפן. כל ההגדרות העסקיות ב-`js/config.js`.

## מבנה האתר
| עמוד | קובץ |
|---|---|
| דף בית (מוצר) | `index.html` |
| איך משחקים + סרטון + הדפסה | `how-to-play.html` |
| לעסקים, מנחים וסדנאות | `business.html` |
| הסיפור | `about.html` |
| שאלות ותשובות (עם FAQ Schema) | `faq.html` |
| תקנון / פרטיות / נגישות | `terms.html` / `privacy.html` / `accessibility.html` |
| 404 | `404.html` |

כותרת, תפריט נייד, פוטר, סל, צ'קאאוט ובאנר עוגיות נבנים פעם אחת ב-`js/layout.js` ומופיעים בכל עמוד. ההתנהגות ב-`js/app.js`. ההגדרות ב-`js/config.js`.

## הסרטון
- `video/how-to-play.mp4` — גרסת אתר (720p, ללא קול, 2.2MB), עם כתוביות HTML שמסתנכרנות לסרטון בעמוד "איך משחקים".
- `video/ou-ou-how-to-play-social.mp4` — גרסה לרשתות (1080×1920) עם כתוביות בעברית צרובות וכרטיס סיום. **בלי מוזיקה** — להוסיף מוזיקה מורשית באינסטגרם/טיקטוק.
- נוצר ב-Higgsfield (Kling 3.0) מתמונת פתיחה שנבנתה לפי עיצוב הקלפים האמיתי. **זו המחשה**: האנשים אינם לקוחות, והקלפים בסרטון ללא טקסט. כך זה מסומן גם באתר. להחליף בצילום אמיתי כשיהיה.

## לא הומצא — ולכן לא מופיע
ביקורות/המלצות, צילומי "לקוחות" (הסרטון מסומן כהמחשה), זמני משלוח, מחירי משלוח, מספר רמות העומק, משך משחק בדקות. כל אחד מהם נכנס כשיש חומר אמיתי.

## חסר להשקה (לפי סדר)
1. **אישורים מרויטל:** מספר הוואטסאפ, השם המלא + מס' עוסק (לתקנון), אילו קלפים נוספים מותר לחשוף ב"שלפו קלף", מספר רמות העומק.
2. **דומיין** + העלאה (GitHub Pages / Netlify / Vercel).
3. **סליקה:** לפתוח חשבון (Grow / PayPlus / מורנינג) ולשים קישור תשלום ב-`paymentUrl`. עד אז — וואטסאפ.
4. **משלוחים:** הצעות מחיר (קרגו / HFD / דואר ישראל) → מחירים ב-`shipping` + זמני אספקה בתקנון ובשאלות.
5. **צילום:** קופסה, קלפים, משחק אמיתי (באישור המשתתפים), תמונה של רויטל → גלריה + "אודות".
6. **סרטון אמיתי** של משחק עם אנשים אמיתיים, להחליף את סרטון ההמחשה.
7. **המלצות אמיתיות** → סקשן הוכחה חברתית.
8. **משפטי:** עו"ד עובר על תקנון ופרטיות; להסיר את סימון "טיוטה".
9. **מדידה:** להכניס מזהי GA4 / פיקסלים ב-`analytics` ב-config, ולעדכן את סעיף העוגיות במדיניות הפרטיות.
10. **סימן מסחר** "או או" — בדיקה ברשות הפטנטים.
11. תמונת שיתוף (og:image) מצילום אמיתי.
12. אחרי חיבור דומיין: `sitemap.xml`, שורת Sitemap ב-`robots.txt`, קישורי canonical.

## סבב שיפורי UX ושיווק (צוות שיווק/המרה + צוות מחקר UX)
בוצע: הזמנה ישירה בלי שלב סל, מסך "עוד צעד אחד" שלא מוחק את הסל עד שהלקוח מאשר שלחץ "שליחה" בוואטסאפ, הסבר ברור שלא משלמים באתר,
מחוון שלבים, שגיאות לכל שדה עם בדיקת טלפון ישראלי, כתובת המקבל במתנה, איסוף עצמי בלי רחוב, פס הזמנה קבוע בנייד, כפתור השהיה לסרטון,
ניגודיות צבעים, נגישות מקלדת ופוקוס, תצוגה תקינה ב-320px, אישור אחרי פניית עסקים, תמונת שיתוף ואייקון מסך בית.

**ממתין להחלטה של רויטל (משפיע מאוד על מכירות):**
1. מחיר משלוח, או לפחות תקרה ("עד X ₪"), וזמן משלוח ("נשלח תוך X ימי עסקים") → `shipping` ב-config + תקנון.
2. צילום אמיתי של הקופסה והקלפים לגיבור בנייד, ותמונה של רויטל.
3. משלוח חינם מ-2 קופסאות (`freeShippingFrom: 280`)? המתחרה הישראלי נותן משלוח חינם.
4. תאריך אחרון להזמנה לחנוכה (רק אחרי שידועים זמני משלוח).
5. פרטי עוסק לתקנון והסרת "טיוטה"; האם אפשר להחליף את תיבת "מסכים לתקנון" בטקסט (באישור עו"ד).
6. מזהי מדידה (GA4 / פיקסל) — בלי זה אי אפשר למדוד את השיפורים.
