# מלאכות הבנייה: אפליקציית לימוד

אפליקציית לימוד בעברית (RTL) לקורס מלאכות בניין בלימודי הנדסאי בניין. סטטית (HTML/CSS/JS), בלי שרת ובלי שלב בנייה בזמן ריצה.

## מבנה התוכן

- **הקורס** (`private/`): שיעורים שנכתבו מתוך חומר הקורס של הסטודנט (צילומי שקפים מהשיעורים).
  כל בלוק תוכן מסומן באחד משלושה סוגים: **מקור** (מה שכתוב בשקף, עם הפניה לעמוד), **הסבר משלים**
  (נוסף כדי להקל על ההבנה) ו**טעון אימות** (קריאה לא ודאית של המקור). הספרייה הזו לא נכנסת לגיט:
  הריפו ציבורי, והחומר שייך למרצה ולסטודנט.
- **ספריית העשרה** (`data/lesson-NN.js`): 15 שיעורים כלליים על מלאכות בניין, שאינם מבוססים על המקור.
  מוצגים בנפרד ולא נכללים במבחנים אלא אם בוחרים בכך.

## יכולות

- דף בית: המשך מהמקום האחרון, התקדמות, רצף ימים, מבחן אחרון, "היום כדאי לחזור על…".
- תוכן הקורס: פרקים נפתחים, זמן משוער, סטטוס וציון לכל שיעור.
- שיעור בשלוש רמות: הבנה מהירה, לימוד מלא, עומק הנדסי. מטרות, מילות מפתח, תיבות "חשוב למבחן",
  "שים לב", "טעות נפוצה", תרשימים לימודיים, תמונות המקור, סימון קטע לחזרה, "הבנתי" לסיום שיעור.
- תרגול: אמריקאית, נכון/לא נכון, פתוחה (עם תשובה לדוגמה ובדיקה עצמית), התאמה, השלמה, השוואה,
  תרחיש מהשטח, סדר פעולות, וזיהוי רכיב בשרטוט (נוצר אוטומטית מהתרשימים). סינון לפי פרק, קושי וסוג.
- מבחנים: לכל פרק ומבחן כולל עם שעון, ניתוח טעויות לפי שיעור וסוג שאלה, היסטוריה.
- כרטיסיות עם חזרה מרווחת (SM-2 מפושט).
- מילון עברית/אנגלית עם מונחים דומים וההבדל ביניהם.
- התקדמות: לפי פרק, נושאים חזקים וחלשים, הצלחה לפי סוג שאלה, המלצות.
- עמודי המקור ודוח כיסוי: כל תמונה, התמלול שלה, מה לא קריא, ובאילו שיעורים היא מופיעה.
- עוזר לימוד (כשהאפליקציה פתוחה כ-Artifact ב-claude.ai): "הסבר לי בפשטות", "דוגמה מהשטח",
  "מה ההבדל", "בחן אותי", "לא הבנתי", ושאלה חופשית. העוזר עונה רק מתוך החומר ומציין עמודי מקור.

- **היום** (דף הבית): מפגש יומי אחד, לפי תוכנית 14 הימים או מפגש אוטומטי (המשך שיעור, כרטיסיות, טעויות), עם המשך מבחן או מקרה שטח שנקטעו.
- **דף פרק** (`#chapter-<id>`): למה זה חשוב, הרעיון המרכזי, בדיקה מקדימה, שיעורים, דף סיכום (`#sheet-<id>`, גם להדפסה), השוואה, קשרים, טריקים לזכירה, מלכודות, מקרי שטח ומבחן פרק.
- **מקרי שטח** (`#cases`, `#case-<slug>`): סיפור בדוי לתרגול, שלב אחר שלב, כל עובדה עם עמוד המקור.
- **תוכנית 14 יום** (`#plan`): משימות לכל יום שמסומנות אוטומטית כשמסיימים אותן, דחייה ביום, טיפים לבחינה.
- **התקדמות מול שליטה**: "התקדמות" = שיעורים שהושלמו; "שליטה" (טרם נבדק / צריך חיזוק / בדרך / שולט) רק על סמך תשובות וכרטיסיות.
- מצב מיקוד בתרגול ובמבחן (בלי ניווט, פס פעולות בתחתית, מבחן שממשיך גם אחרי יציאה), תרשימים עם הגדלה ושלבים, המחשות AI מסומנות, הגדרות (ערכת צבעים, גודל טקסט, תנועה).

ההתקדמות נשמרת בדפדפן, וב-claude.ai גם בחשבון (עוברת בין מכשירים).

## נגישות וביצועים

- מקלדת בלבד: אחרי כל פעולה הפוקוס נשאר על אותו פקד (או על השאלה החדשה / התוצאה), לעולם לא "נופל" לראש הדף;
  חלונות (sheets) לוכדים פוקוס, נסגרים ב-Esc ומחזירים אותו לפקד שפתח אותם; פקד שמקבל פוקוס לא נשאר מוסתר מתחת לסרגלים הקבועים.
- טבלאות רחבות נגללות גם במקלדת (אזור עם שם), מונחים באנגלית מסומנים `lang="en"`, מספר התוצאות בחיפוש ובמילון מוכרז.
- הציור הראשון ממתין עד 0.7 שניות לגופנים בעברית, כדי שהדף לא יקפוץ כשהם נטענים; אם הם איטיים יותר, נשארים בגופני המערכת עד הטעינה הבאה.
- כרטיסים ותמונות קטנות טוענים רק את קובץ ה-640 פיקסלים; הנפשות נטענות רק בלחיצה, ולא מוצגות כשמבקשים תנועה מופחתת.

## לכותבי תוכן

- שאלת השלמה (`cloze`): מקומות עם אותה מילה מתחלפים מעצמם. כשסדר המילים לא משנה (רשימה), אפשר לסמן `anyOrder: true`
  (כל המקומות) או `anyOrder: [[0, 1]]` (קבוצות של מקומות), והבדיקה תקבל כל סדר.

## קבצים

```
index.html            הדף
app.css               עיצוב
app.js                האפליקציה

build.mjs             bundle: private/bundle.js · artifact: דף אחד + src-img/ + media/
tools/validate.mjs    בדיקת תוכן ודוח כיסוי
private/              (לא בגיט) course/*.js, transcripts/*.json, src-img/*.jpg, media/*.webp, bundle.js
  course/_chapters-*.js  COURSE_CHAPTER_EXTRAS: תוספות לכל פרק
  course/_cases.js       COURSE_CASES: מקרי שטח
  course/_plan.js        COURSE_PLAN: תוכנית 14 יום
  course/_media.js       COURSE_MEDIA: המחשות AI (file / small / alt / caption / warn / hide / anim)
  course/_anim.js        COURSE_ANIM: כיתובי שלבים לתרשימים
```

## הרצה מקומית

```
cd melachot
node build.mjs bundle
python3 -m http.server 8080
```

## בדיקה

```
node tools/validate.mjs --coverage private/COVERAGE.md
```

הבדיקה מוודאת שלכל שאלה יש מקור או סימון העשרה, שמפתחות התשובות תקינים, שכל תרשים ועמוד מקור
שמוזכרים קיימים, ושכל עמוד מקור משובץ בשיעור כלשהו.

## גרסת אינטרנט עצמאית

`node build.mjs web <out-dir>` בונה אתר סטטי מלא שאפשר להעלות לכל שירות אחסון (למשל Vercel):
`index.html` עם מסמך HTML מלא, `manifest.webmanifest` וסמלים (התקנה למסך הבית), `sw.js` (עבודה בלי אינטרנט:
הדף מהרשת קודם, תמונות מהמטמון), `robots.txt` ו-`vercel.json` (לא נכנס למנועי חיפוש). קבצי התבנית נמצאים ב-`web/`.
מחוץ ל-Claude אין עוזר לימוד ואין סנכרון בין מכשירים; ההתקדמות נשמרת בדפדפן, ובהגדרות יש שמירה וטעינה של קובץ גיבוי.
