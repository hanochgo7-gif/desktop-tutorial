# מלאכות הבנייה: אפליקציית לימוד

אפליקציית לימוד סטטית (HTML/CSS/JS, בלי שרת ובלי בנייה) לקורס מלאכות בניין בלימודי הנדסאי בניין.

## מה יש בה

- **15 שיעורים**: הסבר מפורק לפרקים, תרשים חתך בסגנון שרטוט, נקודות לזכור, טעויות נפוצות ומילון מונחים.
- **מצב שינון**: מסתיר את מילות המפתח בטקסט ואת "נקודות לזכור", וחושף אותן בהקשה. כך קוראים ובודקים את עצמכם באותו זמן.
- **כרטיסיות עם חזרה מרווחת** (אלגוריתם SM-2 מפושט): כל כרטיסייה חוזרת לפי מידת הזכירה. "לא זכרתי" מחזיר אותה לסבב, "קל" דוחה אותה לימים רבים. עד 15 כרטיסיות חדשות ביום, מתוך השיעורים שסומנו כנקראו.
- **בחנים** לכל שיעור, מבחן מסכם (20 שאלות), בוחן מותאם, ומאגר טעויות שמתרוקן כשעונים נכון.
- **תרגילי סדר פעולות**: מסדרים את שלבי העבודה בשטח לפי הסדר הנכון.
- **חיפוש** בכל המונחים ובכל חומר השיעורים.
- **התקדמות**: שליטה לכל שיעור (קריאה, כרטיסיות, בחנים), רצף ימי לימוד, והצעה לצעד הבא.

ההתקדמות נשמרת בדפדפן (localStorage). כשהאפליקציה פתוחה כ-Artifact ב-claude.ai היא נשמרת גם בחשבון, ועוברת בין מכשירים.

## מבנה הקבצים

```
index.html          הדף (טוען את כל הקבצים)
app.css             עיצוב
app.js              לוגיקה: ניתוב, כרטיסיות, בחנים, תרגילי סדר, חיפוש, שמירה
diagrams.js         תרשימי החתך והדוגמאות (hatch) של החומרים
data/lesson-NN.js   תוכן השיעורים, קובץ לכל שיעור
build.mjs           בונה קובץ HTML יחיד (לפרסום כ-Artifact)
```

## הרצה מקומית

```
cd melachot
python3 -m http.server 8080
```

ואז http://localhost:8080

## הוספה או עריכה של שיעור

כל שיעור הוא קובץ `data/lesson-NN.js` במבנה:

```js
window.LESSONS = window.LESSONS || [];
window.LESSONS.push({
  id: "rebar", num: 5, title: "ברזל זיון", material: "steel", diagrams: ["rebar-cover"],
  summary: "...",
  sections: [{ title: "...", body: ["פסקה עם <b>מילת מפתח</b>", "<ul><li>...</li></ul>"] }],
  remember: ["..."], mistakes: ["..."],
  terms: [{ term: "...", def: "..." }],
  cards: [{ q: "...", a: "..." }],
  quiz: [{ q: "...", options: ["", "", "", ""], answer: 0, explain: "..." }],
  order: [{ title: "...", steps: ["שלב ראשון", "..."] }]
});
```

קובץ חדש צריך גם שורת `<script>` ב-`index.html`. מילים ב-`<b>` הן אלה שמוסתרות במצב שינון.
ההתקדמות בכרטיסיות ובשאלות נשמרת לפי הטקסט שלהן, כך שעריכת ניסוח של שאלה מתחילה אותה מחדש.

## בנייה לקובץ יחיד

```
node build.mjs /path/to/output.html
```
