# רותם גוטובסקי p.m.e Cosmetics: אתר הקליניקה

## מבנה

- `index.html` דף הבית: הירו, מאתר טיפול, טיפולים, לפני/אחרי, לייזר, פדיקור, טיזר חנות, תהליך, שאלות, קביעת תור.
- `shop.html` דף החנות: סינון לפי מותג וסוג מוצר, חיפוש, מיון, תצוגה מהירה. הנתונים ב-`js/products.js` (שדות: brand, name, en, category, desc, size, price, image).
- `css/style.css` עיצוב והנפשות. `js/main.js` אינטראקציות משותפות לשני הדפים.

אתר סטטי בעברית (RTL), עמוד אחד: טיפולי פנים, הסרת שיער בלייזר, פדיקור טיפולי, חנות מוצרים, תהליך, שאלות ויצירת קשר.

## הרצה מקומית
```
cd clinic && python3 -m http.server 8080
```

## מה צריך להחליף לפני עלייה לאוויר
- כתובת האימייל בטופס (`https://formsubmit.co/your@email.com`).
- מחירי המוצרים (`₪ 000`) ושתי תמונות המוצרים החסרות.
- כתובת ושעות פעילות בקטע יצירת הקשר.


## עדכון אוקטובר 2026: שדרוג פרימיום

### מה נוסף
- **עמוד לכל מוצר** (`shop/p/<slug>.html`, 54 עמודים) עם נתונים מובנים (Product, Breadcrumb, FAQ), מוצרים משלימים, הוספה לרשימה ושאלה בוואטסאפ. נבנים אוטומטית: `node tools/build-products.mjs` (גם מעדכן את `sitemap.xml` ואת ה-ItemList בדף החנות).
- **דומיין בפקודה אחת:** `node tools/set-domain.mjs https://your-domain.co.il` מוסיף canonical, og:url, תמונות שיתוף מוחלטות ומעדכן robots ו-sitemap. עד אז הכתובות הן `https://example.com`.
- **עמודים חדשים:** `shop-info.html` (תשלום, משלוחים, החזרות), `privacy.html`, `404.html`.
- **מדידה:** `js/track.js` דוחף אירועים ל-`dataLayer` (קביעת תור, וואטסאפ, חיפוש, הוספה לרשימה, שליחת רשימה, צפייה במוצר, פתיחת העוזרת). כל הודעת וואטסאפ מקבלת שורת "מהאתר: עמוד / מקטע / מקור" כדי לדעת מאיפה הגיעה הפנייה. GA4 נדלק רק אם ממלאים `window.GA_ID` ב-`js/config.js` (מצב הסכמה, בלי עוגיות עד אישור).
- **חיפוש סלחני** בחנות (שגיאות כתיב, חלק ממילה), **קישור טיפול לטופס** (`index.html?goal=...#contact` מסמן את המטרה), **פתיחת הרשימה מקישור** (`shop.html#list`).
- **ביצועים:** וידאו הרקע נטען אחרי העמוד ובמקור אחד בלבד; מאגר הידע של העוזרת (60KB) נטען רק בפתיחת הצ'אט; לוגו ב-webp.
- **נגישות:** שטחי מגע 44px במובייל, ניגודיות מתוקנת, axe נקי בכל העמודים.

### מה עדיין חסר כדי לסיים (ראי CHECKLIST-ROTEM.md)
- מחירים למוצרים (`js/products.js`, שדה `price`). עד אז מוצג "המחיר נמסר בוואטסאפ".
- ספק סליקה לקופה אונליין. כרגע ההזמנה היא רשימה בוואטסאפ, בכוונה: בלי חיוב אוטומטי עד שיש מחירים, מלאי ומסוף. כשיהיה (למשל Grow/משולם או PayPlus), נוסיף שלב תשלום אחרי אישור הזמינות.
- דומיין, ואז `node tools/set-domain.mjs`.
- תמונות מוצר רשמיות (ראי MISSING-IMAGES.md), המלצות אמיתיות, תמונה של רותם והקליניקה.
- מזהה GA4 אם רוצים אנליטיקה חיצונית.
