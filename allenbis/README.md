# Allenbis (אלנביס) – גרסה חדשה

עיצוב ובנייה מחדש של https://www.allenbis.co.il/ – אתר סטטי, בלי שלב בנייה ובלי ספריות.
הגרסה המקורית שהורדה מהאתר החי שמורה בהיסטוריית git (הקומיט "הוספת עותק עבודה של אתר Allenbis").

## הקבצים
| קובץ | מה יש בו |
|---|---|
| `index.html` | מבנה הדף וכל העיצוב (CSS מוטמע, כדי שהדף יוצג מיד) |
| `store.js` | הקטלוג, החיפוש, הסל, בונה הסל לפי תקציב, אימות גיל ותפריט הנגישות |
| `catalog.js` | המוצרים, המחירים והקטגוריות – **ללא שינוי** מהאתר המקורי |
| `commerce-config.js` | הטבות, בונה הסל ושלבי המשלוח – **ללא שינוי** מהאתר המקורי |
| `demo-data.js` | **נתוני דוגמה**: דמי משלוח, מבצעים, הכי נמכרים, חבילות, מוצרים שאזלו, מילים נרדפות לחיפוש ואיורים. כל מה שמסומן `example: true` מוצג באתר עם תווית "דוגמה" |
| `manifest.webmanifest` | מאפשר "הוספה למסך הבית" בטלפון |
| `fonts/` | הגופנים Assistant ו-Secular One (רישיון OFL), מתארחים באתר עצמו |
| `images/` | תמונות המוצרים והפתיחה |
| `_headers` | הגדרות מטמון ל-Cloudflare Pages |

## מה השתפר
**מהירות**
- JavaScript: מ-~480KB (שתי חבילות React) ל-~20KB.
- בקשות בטעינה ראשונה במובייל: מ-32 ל-~19; נתונים: מ-~950KB ל-~365KB.
- הצגה ראשונה (FCP) בבדיקה מקומית: מ-260ms ל-~75ms.
- `_headers` מאפשר מטמון בדפדפן (היום כל קובץ נשלח עם `no-store`).

**עיצוב**
- לוגו בסגנון שלט רחוב תל-אביבי, תוויות מחיר צהובות כמו על המדף.
- בונה הסל לפי תקציב עבר לראש הדף, עם סכומים מהירים.
- סל צדדי במחשב, מגירה תחתונה בנייד; פס סל צף מופיע רק כשיש מוצרים.
- כמות וכפתורי +/− גדולים ונוחים ללחיצה בנייד.

## מה נוסף בעקבות מחקר על האתרים המובילים (Blinkit, Zepto, Instamart, Wolt Market ועוד)
- הבטחת זמן משלוח, שעות ואזור בראש המסך.
- אריחי קטגוריות עם תמונות.
- פסי מוצרים: קנה שוב, מבצעים, הכי נמכרים, עד 10 ₪; וחבילות מוכנות.
- חיפוש עם הצעות תוך כדי הקלדה, חיפושים אחרונים ופופולריים, מילים נרדפות (coke → קולה) וסבילות לשגיאות הקלדה.
- דף מוצר עם "מתאים עם".
- בסל: פס התקדמות למשלוח חינם, "שכחת משהו?", פירוט חיסכון, הנחת היכרות ודמי משלוח.
- הזמנת דוגמה (בלי שליחה לשום מקום) ומעקב משלוח לפי השלבים שב-`commerce-config.js`.

## דרישות חוק שמיושמות בקוד (לבדוק עם עורך דין)
- **מוצרי עישון ואביזרי עישון** (כולל ניירות גלגול): מוצגים בשם ובמחיר בלבד, בלי תמונות, מבצעים, חבילות או המלצות – לפי חוק הגבלת הפרסומת והשיווק של מוצרי טבק. מכירה מגיל 18.
- **אלכוהול**: אי אפשר להוסיף לסל או לשלם בין 23:00 ל-06:00 (שעון ישראל).

## כללים שנשמרו מהאתר המקורי
- מחיר מוצג רק אם `priceReview.status` הוא `verified` או `owner-configured`; אחרת "מחיר יעודכן".
- תמונה מוצגת רק אם `imageReview.status` הוא `verified`; אחרת `fallback.svg`.
- הסל נשמר במכשיר תחת אותו מפתח (`allenbis-cart`), כך שסלים קיימים נשמרים.
- כפתור "להמשך הזמנה" מציג הודעה שההזמנות ייפתחו בקרוב.
- "הכל" מציג את כל המוצרים; אישור גיל נדרש בכניסה לקטגוריות 18+.

## העלאה לאוויר
להעלות את כל התיקייה הזו כפי שהיא ל-Cloudflare Pages (או לכל אחסון סטטי).
