# Allenbis (אלנביס) – עותק עבודה

עותק של האתר החי https://www.allenbis.co.il/ כפי שהורד ב-29.9.2026, לצורך שיפורים.

## מה אפשר לערוך כאן ישירות
- `index.html` – מבנה הדף והטקסטים הקבועים
- `catalog.js` – המוצרים, המחירים והקטגוריות
- `commerce-config.js` – הגדרות תקציב, הטבת היכרות, חבר מביא חבר, גלגל ושלבי משלוח
- `*.css` – העיצוב
- `images/` – תמונות המוצרים והפתיחה

## מה לא לערוך כאן
`app.js` ו-`v2.js` נבנו אוטומטית מקוד JSX שנמצא אצל בעל האתר (`src/client/`, `npm run build`).
שינוי בהם ייעלם בבנייה הבאה – לשינויים בהתנהגות האתר צריך את קוד המקור.

## העלאה לאוויר
האתר מתארח אצל בעל האתר (ככל הנראה Cloudflare). השינויים כאן לא עולים לאוויר אוטומטית –
יש להעביר לו את הקבצים ששונו.
