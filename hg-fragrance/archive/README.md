# Archive

Image masters that the current site does not use: earlier campaign chapters (Riviera, Night Drive,
Rosso, Studio), the editorial bottle stills, the film frames and the three seasonal concepts
(Open Window, Last Light, Nocturne). They live outside `src/` so they are not shipped with the build.

To use one again, move it back to `src/assets/img/` and reference it by name.

October 2026: the images of the red-car (Rosso) campaign's model were removed at the owner's request, so some entries in `campaigns.ts` point at files that no longer exist.
