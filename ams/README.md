# AMS – אביב משה שדמון | Mind & Body Connection

אתר בסיס (עמוד אחד, RTL) למאמן אגרוף תאילנדי, כושר ותודעה. סטטי לגמרי: `index.html`, `css/ams.css`, `js/ams.js`.
כל התוכן נלקח מהאתר הקיים ומהפלייאר, **בלי מחירים**.

## מבנה
- `index.html` – דף הבית: פתיח, מי אני, מטרות, רשימת שירותים (ראשי פרקים בלבד), הגישה, מסלול הדגל, איפה מתאמנים, איך מתחילים, שאלות.
- `services/*.html` – דף לכל שירות: אגרוף תאילנדי, תזונת ספורט ותפריטים, אגרוף + תזונה, הרצאות וסדנאות, אימוני ילדים, גוף ותודעה.
  בכל דף: פירורי לחם, פתיח, הסבר, מה כולל, איך זה עובד, שאלות, קריאה ל־WhatsApp ושירותים נוספים.
- תפריט מסך מלא (בכל הדפים) עם תת־תפריט של כל השירותים.
- `tools/build_pages.py` – מקור התוכן של דפי השירותים, התפריט והפוטר. עורכים שם ומריצים `python3 tools/build_pages.py`.

- **אנליטיקס** (`ANALYTICS` ב־`tools/build_pages.py`): להכניס מזהה GA4 ו/או Meta Pixel ולהריץ את הבנייה. אז מופיע באנר הסכמה (קבלה / דחייה, וכפתור "הגדרות עוגיות" בפוטר), והקוד נטען רק אחרי "קבלה". **באותו שינוי לעדכן את מדיניות הפרטיות** (סעיף העוגיות וצדדים שלישיים ב־`tools/legal.py`).
- **פרטי העסק** (`BUSINESS` ב־`tools/legal.py`): להשלים `tax_id` (מספר עוסק) ו־`email`. הם מופיעים אוטומטית בכל הדפים המשפטיים.
- **ילדים** (`MINORS_CONSENT` ב־`tools/build_pages.py`): התמונה `kids-coach` והסרטון `kids-class` הוסרו עד שיש אישור בכתב מההורים / המסגרת. אחרי האישור:
  `git checkout afb7ba6 -- assets/img/kids-coach.webp assets/img/kids-coach-600.webp assets/video/kids-class.mp4 assets/video/kids-class.webm assets/video/kids-class.webp`,
  לשנות ל־`True` ולהריץ את הבנייה (גם `svc-kids.webp` יחזור מאותו commit אם רוצים את החיתוך המקורי).
- **אנשים בתמונות**: `pads-partner` ו־`training` מראים מתאמנים מזוהים; `fight`, `corner`, `ring` מראים קהל. צריך הסכמה של המצולמים לשימוש מסחרי.
- **טענות**: "מעל 10 שנות ניסיון", "מדריך מוסמך" (וינגייט), הכשרה בתזונת ספורט: מהאתר המקורי של אביב. לשמור תעודות.

- **ביטולים**: לפי חוק הגנת הצרכן (14 יום בעסקת מכר מרחוק, דמי ביטול עד 5% או ₪100, הנמוך). לתת למתאמן את התנאים והמחיר בכתב לפני תשלום.
