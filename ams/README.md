# AMS – אביב משה שדמון | Mind & Body Connection

אתר בסיס (עמוד אחד, RTL) למאמן אגרוף תאילנדי, כושר ותודעה. סטטי לגמרי: `index.html`, `css/ams.css`, `js/ams.js`.
כל התוכן נלקח מהאתר הקיים ומהפלייאר, **בלי מחירים**.

## מבנה
- `index.html` – דף הבית: פתיח, מי אני, מטרות, רשימת שירותים (ראשי פרקים בלבד), הגישה, מסלול הדגל, איפה מתאמנים, איך מתחילים, שאלות.
- `services/*.html` – דף לכל שירות: אגרוף תאילנדי, תזונת ספורט ותפריטים, אגרוף + תזונה, הרצאות וסדנאות, אימוני ילדים, גוף ותודעה.
  בכל דף: פירורי לחם, פתיח, הסבר, מה כולל, איך זה עובד, שאלות, קריאה ל־WhatsApp ושירותים נוספים.
- תפריט מסך מלא (בכל הדפים) עם תת־תפריט של כל השירותים.
- `tools/build_pages.py` – מקור התוכן של דפי השירותים, התפריט והפוטר. עורכים שם ומריצים `python3 tools/build_pages.py`.

## קידום אורגני (SEO)

**מחקר מילים (השלמה אוטומטית של גוגל, אוקטובר 2026):**

- חיפושים מקומיים קיימים: "אגרוף תאילנדי מזכרת בתיה", "מאמן (כושר) אישי מזכרת בתיה", "איגרוף תאילנדי רחובות", "מאמן אישי רחובות", "קיקבוקס רחובות", "אגרוף תאילנדי גדרה", "אגרוף תאילנדי נס ציונה".
