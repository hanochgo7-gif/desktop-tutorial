# SOTA: אתר ייעוץ IT

אתר דו-לשוני (עברית RTL ואנגלית LTR) ל-SOTA, עם מערכת לפניות של לקוחות חדשים, מערכת קריאות שירות ללקוחות קיימים וממשק ניהול לצוות.

## הקונספט

**המסלול.** טכנולוגיה היא סבך של קווים, ו-SOTA משרטטת דרכו מסלול אחד ברור. השפה הגרפית לקוחה ממפות תחבורה: קווים ישרים, פניות של 45°, תחנות כטבעות ואות ירוק אחד. הלוגו בנוי מאותם רכיבים (ה-O היא תחנה). מערכת המותג המלאה נמצאת ב-`/brand/`.

מבנה האתר לפי סוג הלקוח: מיד אחרי הפתיח, "מה מתאר אותך?" עם ארבע דלתות (פרטיים, עסקים קטנים, עסקים בצמיחה, לקוחות קיימים). לכל סוג לקוח עמוד משלו: הבעיות שלו, איך עוזרים לו, שאלות שאנשים כמוהו שואלים, שאלות נפוצות וטופס שבו סוג הלקוח כבר מסומן. התפריט בנוי לפי סוגי הלקוחות.

מסע המשתמש בדף הבית: חשיפה (רשת מסלולים חיה) → זיהוי הבעיה (סבך שמתיישר בגלילה) → הגישה (ארבע תחנות על מסלול מוצמד) → תחומים → למה SOTA (פרק בהיר, 25 שנה) → למי זה מתאים → ייעוץ ראשוני (טופס) → המלצות (מוצג רק כשיש) → שאלות → סיום.

## מבנה

```
index.html, en/index.html            דף הבית בעברית ובאנגלית (נוצרים מ-content/)
private/, small-business/,
growing-business/ (+ en/)             עמוד לכל סוג לקוח: פרטיים, עסקים קטנים, עסקים בצמיחה
service/, en/service/                 פתיחת קריאת שירות
privacy/, accessibility/ (+ en/)      מדיניות פרטיות והצהרת נגישות
brand/                                מערכת המותג (לא נסרק)
admin/                                ממשק הניהול לצוות (לא נסרק)
content/site.mjs                      פרטי קשר, דומיין, מזהי מדידה
content/he.mjs, content/en.mjs        כל הטקסטים
content/legal.json                    טקסט הפרטיות והנגישות
tools/build.mjs                       בונה את כל העמודים, sitemap, robots ו-js/config.js
css/sota.css                          מערכת העיצוב
js/main.js, js/forms.js, js/track.js  התנהגות, אנימציות, טפסים, מדידה
server/                               השרת: Cloudflare Worker + D1 + R2
_headers                              כותרות אבטחה (CSP, HSTS וכו')
```

אחרי כל שינוי בטקסט או בהגדרות: `node sota/tools/build.mjs` (מתיקיית הריפו).

## מה עובד

- **טופס ייעוץ ראשוני**: ולידציה בדפדפן ובשרת, שמירה במסד הנתונים, התראה במייל לעסק, הודעת הצלחה, אירוע `generate_lead`.
- **קריאות שירות**: עמוד נפרד, סוג תקלה, דחיפות, צירוף קובץ עד 10MB (נבדק לפי תוכן הקובץ, לא רק לפי הסיומת), מספר קריאה ייחודי (`SOTA-XXXXXX`), התראה לעסק (עם תגית "קריטי"/"דחוף"), אישור במייל ללקוח, אירוע `ticket_open`. נשמרות בנפרד מהפניות של לקוחות חדשים.
- **ממשק ניהול** (`/admin/`): סקירה, קריאות (סטטוס, דחיפות, שיוך לאיש צוות, הערות פנימיות, היסטוריה, צפייה בקובץ), פניות (סטטוס), המלצות (הוספה, עריכה, הצגה באתר), פרטי קשר (מתעדכנים באתר בלי קוד), ניהול צוות, החלפת סיסמה. שתי הרשאות: מנהל (הכול) וצוות (קריאות ופניות).
- **אבטחה**: סיסמאות ב-PBKDF2, סשן בעוגייה HttpOnly + SameSite=Strict, הגנת CSRF, הגבלת קצב (טפסים וכניסה), מלכודת דבש, זמן מילוי מינימלי, Turnstile אופציונלי, שאילתות עם פרמטרים בלבד, הצגת תוכן כטקסט בלבד בממשק, קבצים מוגשים עם `nosniff` ו-`sandbox`, CSP מחמיר, סודות רק ב-Wrangler secrets.
- **בדיקה מהירה (60 שניות)**: שש שאלות כן/לא על מצב המחשוב בעסק, לאורך מסלול. בסוף: ציון, נקודות לבדיקה עם הסבר קצר, וכפתור שממלא את טופס הייעוץ עם התוצאה. לא נשלח כלום בלי שהגולש שולח את הטופס. אירועים: `check_start`, `check_complete`.
- **שאלות לדוגמה** מתחת לכל תחום ייעוץ, **"מה קורה אחרי ששולחים"** ליד הטופס, **סרגל פנייה קבוע במובייל** (נעלם כשהטופס או הבדיקה על המסך) ולוגו גדול בתחתית האתר.
- **מדידה**: `dataLayer` לכל האירועים (וואטסאפ, טפסים, קריאה, תיאום פגישה, החלפת שפה, טלפון, בדיקה מהירה). GTM או GA4 נטענים רק אם הוגדר מזהה ורק אחרי הסכמה בבאנר (Consent Mode v2).
- **SEO**: כותרות ותיאורים לכל עמוד, canonical, hreflang (he, en, x-default), Open Graph עם תמונה לכל שפה, sitemap עם חלופות שפה, robots, נתונים מובנים (ProfessionalService, FAQPage, WebSite).
- **נגישות**: axe נקי (WCAG 2.2 AA + best practices) בכל העמודים, בדסקטופ ובמובייל. ניווט מקלדת, קישור דילוג, הודעות שגיאה מוקראות, כיבוד "הפחתת תנועה", RTL/LTR מלאים.

## מה חסר כדי לעלות לאוויר

פרטים מבעל העסק (מסומנים `TODO` בקבצים):

1. **דומיין**: `siteUrl` ב-`content/site.mjs`.
2. **טלפון, וואטסאפ ואימייל**: ב-`content/site.mjs`, או אחרי ההעלאה בממשק הניהול ← פרטי קשר. עד שיש מספר, כפתורי הוואטסאפ מוסתרים והכפתור "בואו נדבר" מוביל לטופס.
3. **קישור לתיאום פגישה** (Google Calendar Appointment Schedule, Cal.com או Calendly): בלעדיו "תיאום שיחת ייעוץ" מוביל לטופס.
4. **הצהרת נגישות**: שם רכז הנגישות. **מדיניות פרטיות**: שם משפטי, ח"פ/ע"מ, תקופת שמירה, תאריך עדכון (`content/legal.json`).
5. **אישור תוכן**: הטקסטים בעמודי סוגי הלקוחות (`audiences` ב-`content/he.mjs` ו-`en.mjs`), תחומי הייעוץ והשאלות לדוגמה שמתחתיהם, שאלות הבדיקה המהירה, התשובות בשאלות הנפוצות (במיוחד תנאי הליווי החודשי) וסוגי התקלות בטופס הקריאה נכתבו לפי המידע שנמסר, וצריך שבעל העסק יעבור עליהם.
6. **המלצות**: רק אמיתיות, באישור הלקוח, דרך ממשק הניהול.

## העלאה לאוויר (Cloudflare, כ-20 דקות)

צריך חשבון Cloudflare (החבילה החינמית מספיקה), חשבון Resend למיילים, ו-Node.js.

```bash
cd sota/server
npm install
npx wrangler login

# מסד נתונים ואחסון קבצים
npx wrangler d1 create sota            # להעתיק את database_id ל-wrangler.toml
npx wrangler r2 bucket create sota-files
npm run db:init                        # יוצר את הטבלאות

# סודות
npx wrangler secret put SESSION_SECRET     # מחרוזת אקראית ארוכה: openssl rand -base64 48
npx wrangler secret put RESEND_API_KEY     # מ-resend.com, אחרי אימות הדומיין
npx wrangler secret put TURNSTILE_SECRET   # לא חובה: Cloudflare > Turnstile

# ב-wrangler.toml: NOTIFY_EMAIL, MAIL_FROM, ADMIN_URL
npm run deploy

# משתמש מנהל ראשון
npm run user:add -- --email you@domain.co.il --name "השם שלך" --role admin --remote
```

אחר כך ב-Cloudflare: Workers & Pages ← sota ← Settings ← Domains & Routes ← להוסיף את הדומיין. אם הדומיין עדיין לא ב-Cloudflare, מעבירים את ה-DNS שלו אליהם (בלי לגעת ברשומות MX של המייל).

אם מגדירים Turnstile, מכניסים את ה-Site Key ל-`turnstileSiteKey` ב-`content/site.mjs` ובונים מחדש.

**אחרי העלייה:** Google Search Console (אימות הדומיין, הגשת `sitemap.xml`), Google Business Profile, ומזהה GTM או GA4 ב-`content/site.mjs`.

## פיתוח ובדיקות מקומיות

```bash
cd sota/server
npm install
echo 'SESSION_SECRET=local-dev-secret-0123456789abcdef0123456789' > .dev.vars
npm run db:init:local
SOTA_PASSWORD='TestPassword-1234' npm run user:add -- --email admin@sota.test --name "בדיקה"
npm run dev                            # http://127.0.0.1:8787 (האתר + השרת)
npm test                               # 19 בדיקות API מול השרת המקומי
```

בלי שרת (`python3 -m http.server` בתיקייה) האתר עובד במלואו, והטפסים מציגים הודעה שהם עוד לא מחוברים, עם הפניה לוואטסאפ.

## למה לא Next.js

הבריף הזכיר React/Next.js. בחרנו באתר סטטי מהיר + Worker אחד, כי זה מה שהאתר הזה צריך: אין כאן תוכן דינמי שמצדיק רינדור בשרת, הטעינה מהירה יותר (HTML מוכן, JS קטן), אין שרת Node לתחזק, והאתר מתארח באותה שיטה כמו שאר האתרים בריפו. ה-API, מסד הנתונים, הקבצים והאתר יושבים על אותו דומיין, בחינם עד נפחים גדולים בהרבה מהצפוי.
