Accessibility Statement

Last updated: TODO: תאריך עדכון

At SOTA we want everyone to be able to use this website comfortably, including people with disabilities. The site was built to Israeli Standard 5568 at level AA, which is based on the WCAG guidelines, in line with Israel's Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 2013.

What we've done

  • Full keyboard navigation, a clearly visible focus indicator and a "skip to content" link.
  • A semantic heading structure and clear labels on every form field, with error messages announced to screen readers.
  • Color contrast that meets the standard, and text that can be enlarged to 200% without losing content.
  • Support for your operating system's "reduce motion" setting: when it's on, animations stop and content appears immediately.
  • Right-to-left Hebrew and left-to-right English, with the correct language set on every page.
  • A fully responsive layout for phones and screens of all sizes.

Known gaps

We keep testing and improving. If you find something that isn't accessible, please let us know and we'll fix it.
