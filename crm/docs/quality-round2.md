# סבב איכות 2

שלוש בדיקות במקביל: בדיקת קוד (באגים שמאבדים נתונים או מציגים מספרים שגויים), פאנל לקוחות עם חמש דמויות חדשות
(מאפרת כלות עוסקת פטורה, חשמלאי, סוכנות דיגיטל, מנהל חשבונות בדימוס, משתמשת ראשונה), ובדיקת עיצוב ונגישות
(כל מסך במחשב, בטלפון ובמצב כהה, ו-axe-core). לכל תיקון נוספה בדיקה אוטומטית.

## נתונים וסנכרון (בדיקת קוד)

| ממצא | תיקון |
|---|---|
| שגיאת שרת זמנית (503/429) בזמן שליחת שינויים ששמורים לשליחה מחקה אותם | שומרים אותם ומנסים שוב. שינוי שהשרת דחה טוען מחדש את הרשומה מהשרת |
| עריכה בזמן שהרשומה נשלחת אבדה | העריכה נשלחת בנפרד אחרי השליחה |
| כתיבה ישירה שנכשלה ברשת לא נוסתה שוב | ניסיון חוזר אוטומטי |
| שתי כתיבות מהירות לאותה רשומה יכלו להגיע הפוך | נשלחות לפי הסדר |

## כסף ומע"מ

| ממצא | תיקון |
|---|---|
| עוסק פטור: תשלום בעסקה קוצץ ב-18% מע"מ | שיעור המע"מ לפי ההגדרות. לעוסק פטור אין מע"מ ואין תיבת "כולל מע"מ" |
| ניתוק או קישור של מסמך ששולם לעסקה הכפיל או מחק הכנסה | כל תשלום נספר פעם אחת לפי המזהה שלו, ותשלומים עוברים עם המסמך לעסקה החדשה |
| ביטול מסמך ששולם, או מחיקת העסקה שלו, מחק הכנסה שהתקבלה | כסף שהתקבל נשאר הכנסה. ההודעה מסבירה מה קורה |
| מחיקת תשלום בעסקה השאירה את המסמך "שולם" | נמחק גם במסמך, והמסמך פתוח שוב |
| קבלה שנרשמה מתוכנת החשבוניות הוצגה "ממתינה לתשלום" ונספרה פעמיים | קבלה מוצגת כשולמה ונרשמת כהכנסה פעם אחת (אפשר לבטל אם כבר נרשם בעסקה) |
| חשבונית זיכוי נספרה כחוב | לא חוב. בייצוא לרו"ח היא שלילית |
| מקדמה על עסקה פתוחה לא הופיעה ביתרות לגבייה | מופיעה |
| מסמך מודפס עוגל לשקלים (4,370 במקום 4,370.34) | מסמכים ותשלומים באגורות. דוחות בשקלים שלמים |
| ותק חובות הראה 0, וחוב של היום "‎-1 ימים" | ימים מתחילת היום, אף פעם לא שלילי |
| פאנל המע"מ הציג את התקופה הנוכחית | הדיווח הקרוב: התקופה הקודמת עד ה-15 בחודש. נוספה "תקופת מע"מ קודמת" |
| ייצוא לרו"ח בלי הוצאות פרסום | שורות פרסום לפי מקור, סה"כ פרסום ורווח |
| אפשר היה להקטין מסמך ששולם מתחת לסכום ששולם | נחסם עם הסבר |
| "מחיקת נתוני הדוגמה" מחקה גם הוצאות פרסום אמיתיות | נמחקות רק הוצאות הדוגמה, ומסמכים והוצאות של עסקאות הדוגמה |
| עריכת הוצאה ישנה חישבה מחדש את המע"מ לפי השיעור של היום | החלוקה נשמרת אם הסכום לא השתנה |
| | קטגוריית הוצאה "חומרים ומלאי", הערה על מע"מ רכב |

## שימוש יומיומי (פאנל)

- הקשה כפולה על "שמירה" יצרה כפילויות (עסקאות, מסמכים, הוצאות, שיחות): עכשיו נשמר פעם אחת.
- Enter שומר בכל חלון. "חזרה" אחת עוזבת דף ליד חדש. אחרי מחיקת ליד או עסקה מגיעים לרשימה.
- ייבוא CSV: "אינסטגרם ממומן" הוא Meta Ads ו"אינסטגרם" אורגני, המלצות הן הפניה, ו-"Google" לבד נשאר לא ידוע.
  קובץ בקידוד העברית של אקסל נקרא נכון.
- לידים מיובאים לא מציפים את "היום שלי": מעל 3 הם מקובצים לשורה אחת. יש "הצגת הכול" מעל 40 פריטים.
- חשבון חדש: "איך מתחילים" במקום "הכול מטופל". עם נתוני דוגמה מוצג פס שמסביר איך מוחקים אותם.
- טלפון עם אות (O במקום 0) או מספר ספרות לא תקין נדחה עם הסבר.
- עוסק פטור: בלי "חשבונית מס" ובלי "כולל מע"מ" בחלונות ובמסמך המודפס.
- חלון התשלומים בטלפון: כרטיס לכל תשלום. כפתורים בגובה 44px במסכי מגע.
- טיוטה שנשמרה מוצגת ברשימת הטיוטות. "חזרה" מדף ההדפסה חוזר לעסקה.
- ניסוח: "הצעד הראשון", "מעקב", "צפי לפי סיכוי", ושני ה"רווח" מוסברים (כסף שנכנס מול עסקאות שנסגרו).

## עיצוב ונגישות

- ניגודיות לפי WCAG AA: ירוק, אדום וכתום כהים יותר. הודעות קופצות קריאות במצב כהה.
- מצב כהה: כרטיסים בהירים מהעמודות, וקו הפרדה לסרגל הצד.
- לוח העסקאות: אדום רק לעסקה שעברה את היעד בשלב, וכתום ל"אין צעד הבא".
- טבלת הלידים: שם ועסק בשתי שורות. ערכים באנגלית ומספרים מיושרים עם העברית.
- כפתור ראשי אחד בכל מסך. כפתורי מחיקה אדומים.
